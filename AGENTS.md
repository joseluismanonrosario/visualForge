# Reglas del Proyecto / Directrices de Desarrollo

## Regla de Alcance Estricto (Strict Scope Rule)
- **Modificaciones y adiciones estrictamente acotadas**: Modifica y agrega únicamente lo que el usuario pida de forma explícita.
- **Sin cambios no solicitados**: No realices refactorizaciones no pedidas, no modifiques archivos ajenos al alcance de la solicitud ni introduzcas funcionalidades, librerías o dependencias adicionales por iniciativa propia.
- **Preservación del código existente**: Conserva la funcionalidad existente, estilos y código previamente aprobado a menos que el usuario indique explícitamente su reemplazo o eliminación.
